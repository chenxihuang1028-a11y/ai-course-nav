# AI 名校免费课程中文导航

把几所学校真实开放、免费的 AI 课程,按人群分类整理,配上中文摘要笔记,方便中文读者按图索骥地学。

## 这个仓库是什么,不是什么

- ✅ 是一份"课程地图":哪门课讲什么、适合谁、去哪看原视频
- ✅ 每门课附中文摘要笔记(基于公开课程页面/大纲整理)
- ✅ 视频统一链回 YouTube / edX 官方原始链接观看
- ❌ 不下载、不剪辑、不重新上传任何课程视频(原始视频版权归各校/主讲人所有,标准 YouTube 协议不允许二次分发)
- ❌ 不是完整逐字稿翻译,是导航+摘要,细节以原视频为准

## 中文字幕怎么看

打开 YouTube 播放器 → 点击右下角"设置"(齿轮图标) → 字幕/CC → 选择"自动翻译" → 中文。
大部分名校课程官方自带英文字幕,YouTube 自动翻译成中文的可用度已经不错,不需要我们额外做字幕。
