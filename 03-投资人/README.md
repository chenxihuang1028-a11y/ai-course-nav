# 03 · 投资人

适合想看懂AI赛道、判断项目靠不靠谱,但不打算自己写代码的人。目标是搞懂术语+建立基本判断力,不是成为工程师。

## Stanford CS336 · Language Modeling from Scratch(打技术底)

- playlist:https://www.youtube.com/playlist?list=PLoROMvodv4rOY23Y0BoGoBGgQ1zmU_MT_
- 中文摘要:不需要全部跟着写代码,但过一遍能建立起"预训练/推理/Scaling/MoE"这些术语的直觉,业内有观点认为,做基本的AI投资判断,过一遍这门课的核心概念就差不多够用了(这是行业内的一种说法,不是官方定位,仅供参考)
- 完全免费,YouTube直接看,不用登录

## DeepLearning.AI · AI For Everyone

- 官方页面:https://www.deeplearning.ai/courses/ai-for-everyone
- ⚠️ 实际入口在Coursera,选"Audit/旁听"完全免费,只有要证书才收费,不用证书全程不涉及付款,但需要注册免费Coursera账号
- 中文摘要:不需要代码基础,4周讲清AI术语和企业AI项目怎么规划的,适合先补一下基础再看CS336
