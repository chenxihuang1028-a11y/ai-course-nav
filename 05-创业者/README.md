# 05 · 创业者

适合想把AI用到自己生意里、但不打算自己下场写代码的人。目标是"知道AI能帮我的生意解决什么具体问题",不是学技术本身。

## DeepLearning.AI · AI For Everyone

- 官方页面:https://www.deeplearning.ai/courses/ai-for-everyone
- ⚠️ 实际入口在Coursera,选"Audit/旁听"完全免费,只有要证书才收49美金,不用证书全程不涉及付款,但需要注册免费Coursera账号
- 中文摘要:零代码零基础,4周讲清楚AI能做什么不能做什么、怎么在自己的组织/生意里规划一个AI项目
- 适合:完全没接触过AI、想先建立基本判断力的创业者

## DeepLearning.AI · Generative AI for Everyone

- 官方页面:https://www.deeplearning.ai/courses/generative-ai-for-everyone
- 同样免费旁听(Coursera,不要证书不花钱)
- 中文摘要:专讲生成式AI能力边界、怎么在业务场景里找应用点,可以当成AI For Everyone的进阶版
