# 01 · 小白入门

适合完全没有编程/数学基础,只想搞懂"AI到底是什么、能干什么"的人。

## Harvard CS50's Introduction to AI with Python

- **YouTube完整课程(真正免费,不用登录不用注册)**:https://www.youtube.com/playlist?list=PLhQjrBD2T382Nz7z1AEXmioc27axa19Kv
- 单集直接看 Lecture 0 · Search:https://www.youtube.com/watch?v=WbzNRTTrX0g
- 官方课程材料站(免费,含习题集,不是付费页):https://cs50.harvard.edu/ai/2020/weeks/0/
- ⚠️ 之前贴的edX链接会跳到一个看着像付费的页面,换成上面这个YouTube版和官方材料站,内容完全一样,不用注册不用登录
- 主讲:David J. Malan / Brian Yu
- 时长:7周
- 中文摘要:从图搜索、分类问题、优化算法一路讲到大语言模型,每周配一个动手小项目(比如做一个下棋AI、做一个手写数字识别)。比"AI For Everyone"更硬核一点,需要跟着写一点Python代码,但不要求提前会编程。
- 适合:想稍微沾一点代码、又不想直接啃数学推导的入门者

## DeepLearning.AI · AI For Everyone

- 官方页面:https://www.deeplearning.ai/courses/ai-for-everyone
- 主讲:Andrew Ng
- 时长:4周,每周2-3小时
- ⚠️ 实际入口在Coursera,选"Audit/旁听"模式完全免费看全部内容,只有想要证书才收49美金,不想要证书的话全程不涉及付款,但需要注册一个免费Coursera账号
- 中文摘要:完全不需要编程和数学基础,讲AI术语、AI能做什么不能做什么、企业里怎么规划AI项目。是吴恩达专门给非技术人群做的课。
- 适合:完全零基础、不打算写代码、只想能听懂AI话题的人
