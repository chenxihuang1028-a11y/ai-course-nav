# 05 · 创业者

适合想把AI用到自己生意里、但不打算自己下场写代码的人。目标是"知道AI能帮我的生意解决什么具体问题",不是学技术本身。

## Y Combinator · Startup School

- 官网:https://www.startupschool.org/
- YouTube也能直接看,不需要申请,不需要付费
- 主讲:YC CEO Michael Seibel(怎么规划MVP)、YC合伙人Adora Cheung(怎么排优先级)、YC合伙人Eric Migicovsky(怎么跟用户聊)
- 中文摘要:YC真人授课教你怎么把一个想法变成公司,从MVP到找用户到冷启动,是全球最知名的创业加速器公开的免费内容
- 适合:想把AI用到自己生意里、或者想学怎么正经做一家公司的创业者

---

⚠️ **原来这里放的是DeepLearning.AI两门课,需要注册Coursera账号才能免费旁听,换成了完全无门槛、不用注册的YC Startup School。** 之前还放过一门MIT Sloan的"AI战略"课,核实后发现要3850美金,已经删掉。

👉 YC Startup School覆盖的是"怎么开公司"这个更根本的问题,AI只是你要卖的东西之一,这个视角对创业者可能比单纯讲AI术语的课更有用。
