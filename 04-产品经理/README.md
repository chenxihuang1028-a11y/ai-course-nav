# 04 · 产品经理

适合非技术背景,但需要设计AI产品、跟工程师对齐需求的人。跟"小白入门"不一样的地方在于,这里更侧重"能落地成产品",不只是听懂概念。

## DeepLearning.AI · Generative AI for Everyone

- 官方页面:https://www.deeplearning.ai/courses/generative-ai-for-everyone
- ⚠️ 实际入口在Coursera,选"Audit/旁听"完全免费,不要证书全程不涉及付款,但需要注册免费Coursera账号
- 主讲:Andrew Ng
- 中文摘要:专讲生成式AI能力边界、怎么在业务里找到应用场景、怎么跟技术团队沟通需求,不需要写代码
- 适合:想理解生成式AI产品设计逻辑、评估一个AI功能是否该做的产品经理

## DeepLearning.AI · AI For Everyone(补基础)

- 官方页面:https://www.deeplearning.ai/courses/ai-for-everyone
- 同样免费旁听(Coursera,不要证书不花钱)
- 中文摘要:如果对AI基础术语还不熟,建议先补这门再看上面那门,内容不重复,一个讲通用AI，一个专讲生成式AI

---
👉 顺序建议:AI For Everyone打术语基础 → Generative AI for Everyone学怎么落地成产品决策。
